# WayMate 🚗

**Smarter airport ridesharing, together.**

WayMate is an airport ridesharing application that connects passengers traveling to similar destinations, helping them share rides, reduce travel costs, and make airport transfers more convenient.

## ✨ Planned Features

- ✈️ Airport ride booking with flight and arrival details
- 🤝 Smart passenger matching based on destination, arrival time, and ride preferences
- 🚘 Shared ride pooling and driver assignment
- 🗺️ Live driver tracking and pickup coordination
- 💳 Secure in-app payments
- ⭐ Driver ratings and reviews
- 🔔 Real-time notifications

## 🛠️ Tech Stack

| Component | Technology |
|---|---|
| Mobile App | React Native |
| Backend | Java, Spring Boot |
| Database | PostgreSQL (Supabase) |
| Maps & Navigation | Google Maps Platform |
| Authentication | Spring Security, JWT, Google Sign-In |
| Payments | Razorpay |
| Push Notifications | Firebase Cloud Messaging |
